# Tech Stack & Tooling

The projects in this repository utilize the following core libraries and tools:

*   **Language:** Python

Across these projects, I explore and evaluate multiple machine learning architectures:

*   **Clustering / Unsupervised:** K-Means, PCA (Principal Component Analysis).
